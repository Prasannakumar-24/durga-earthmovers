# Hero Images

Place your hero images here:

- `hero-poster.jpg` - Fallback image for hero video background
- `video-poster.jpg` - Poster image for video showcase section

Recommended dimensions:
- Hero poster: 1920x1080px (16:9 aspect ratio)
- Video poster: 1920x1080px (16:9 aspect ratio)

These images should show:
- Construction/earthmoving machinery
- Excavation work
- Industrial/construction scenes
- Professional earthmoving operations
