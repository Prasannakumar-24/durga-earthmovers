# Project Showcase Video

Place your project showcase video here:

- `project-showcase.mp4` - Video showcase section

Recommended specifications:
- Format: MP4 (H.264 codec)
- Resolution: 1920x1080 (1080p)
- Duration: 1-3 minutes
- File size: Under 50MB for optimal loading
- Content: Various projects and machinery in action

Video requirements:
- Show multiple project types
- Professional editing
- Clear audio (optional, can be muted)
- Good lighting and composition
- Show equipment capabilities
